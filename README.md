Implementation of different acceleration structures for ray tracing and comparison of these acceleration structures.

Implemented acceleration structures are the following:
- Uniform Grid Structure
- Sliding Midpoint k-D Tree Structure
- Bounding Volume Hierarchy Structure

Details of the development and results of the term project is available in the following blog post:

https://erenceng795.wordpress.com/2025/01/23/final-project-acceleration-structures

----------------------------------------------------------------------------------------

Running the following command on the terminal will create the executable ray tracer:

make

Running the following command on the terminal will start the rendering process of my ray tracer:

./raytracer scene.xml
